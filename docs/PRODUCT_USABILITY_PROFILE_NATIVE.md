# Product Usability Profile — Тренажёр для Андрея (нативная версия)

> **Заморожено 2026-09-19.** Действующий профиль — `PRODUCT_USABILITY_PROFILE.md`: основная версия теперь веб-приложение (PWA). Этот файл — история решений нативной версии.

Стандарт на момент заморозки — v1.4 (сейчас в `USABILITY_STANDARD.md` v1.5; оригинал — `~/Claude-Workspace/СТАНДАРТ-ЮЗАБИЛИТИ-ДЛЯ-НОВЫХ-ПРОДУКТОВ.md`).
Обновлено: 2026-09-18, после первой итерации разработки (MVP написан, на устройстве ещё не проверялся).

## Аудитория и контекст

- Основной пользователь — Андрей, один человек. Домашние силовые тренировки с гантелями.
- Устройства: iPhone и iPad, один Apple ID. Телефон лежит рядом на полу или на скамье, руки заняты гантелями — важны крупные кнопки и минимум касаний между подходами.
- С 2026-09-19 — без платного Apple Developer: данные на каждом устройстве свои, установка из Xcode с переподписью раз в 7 дней.
- Возвращается несколько раз в неделю, тренировка — от 30 минут до 1,5 часа.
- Автор контента — Женя, не пользуется приложением, ведёт таблицу и папки Drive. Нетехнический пользователь.

## Основная ценность

- Первая ценность: быстро начать тренировку. Готовую — за 3 касания (главный → список → «Начать»); повторить свою — за 4 (выбор сохраняется между тренировками).
- Что продолжить при следующем открытии: незавершённую тренировку (карточка «Продолжить» на главном экране).
- Завершённая сессия: «Нет, закончить» после вопроса «Ещё хочешь?» или «Завершить и сохранить» из меню — запись уходит в историю.

## Доменные объекты

| Объект | Кто создаёт | Состояния / поля | Хранение |
|---|---|---|---|
| Упражнение, раздел (часть тела), готовая тренировка | Женя (таблица) → система (манифест) | версия; фото и видео — скачано / нет | Манифест JSON + медиа, только чтение |
| Черновик своей тренировки | Андрей | выбранные части тела и упражнения | UserDefaults, переживает выход и перезапуск |
| Идущая тренировка (сессия) | Андрей | упражнение, отмеченные подходы, фаза: карточка → «Ещё хочешь?» → добор | JSON на диске после каждого действия |
| Запись истории | Система при завершении | дата, тип, части тела, упражнения, длительность | Core Data на устройстве (CloudKit выключен) |
| Избранное | Андрей | упражнение или тренировка | Core Data на устройстве (CloudKit выключен) |
| Настройки | Андрей | таймер, напоминания, видео заранее | UserDefaults на устройстве (iCloud KVS выключен) |
| Замечание к контенту | Система | ошибка / поправить / для сведения | В манифесте |

## Прямые и обратные действия

| Прямое действие | Обратное | Что сохраняется | Реализация |
|---|---|---|---|
| Выбрать часть тела / упражнение | Снять отметку; «Сбросить выбор» | Черновик | Повторное касание, кнопка |
| Шаг мастера «части тела → упражнения» | Назад без потери выбора | Черновик | Навигация «назад» |
| Начать тренировку | Свернуть и вернуться; завершить с сохранением; прервать | Сессия на диске | ⌄ на экране тренировки, «Продолжить» на главном |
| Подход выполнен | Снять отметку последнего подхода | Счётчик подходов | Кнопка ↶ |
| Запустить отдых | Пропустить; +15 с | Время окончания | Кнопки на панели таймера |
| Следующее упражнение | Предыдущее | Позиция и подходы каждого упражнения | ‹ на нижней панели |
| Список закончился → «Ещё хочешь?» | Вернуться к последнему упражнению | Сессия | Кнопка на экране вопроса |
| «Да, хочу ещё» | Назад к вопросу | Сессия | «Назад» на экране добора |
| Добавить упражнения при доборе | Нет отдельного — продолжить или завершить | Очередь сессии | — |
| Завершить тренировку | Удалить запись из истории | Снимок записи | Детали истории → «Удалить» → тост «Отменить» |
| Прервать без сохранения | Необратимо | — | Подтверждение с названием последствий |
| ♡ добавить | ♡ снять | Элемент избранного | Тост «Отменить» при снятии |
| Удалить запись истории | «Отменить» (4 секунды) | Полный снимок записи, тот же ID | Повторное добавление без дублей |
| Изменить настройку | Вернуть значение | Настройки, `updatedAt` | Тот же контрол |
| Включить напоминания | Выключить; изменить время и дни | Расписание | Переключатели (с iCloud — ещё «только на этом устройстве») |
| Отказ в уведомлениях | Путь в настройки iOS | — | Кнопка «Открыть настройки iOS» |
| Удалить скачанные видео | Скачаются заново при просмотре или по Wi-Fi | Манифест не трогается | Подтверждение с объёмом |
| Обновление контента (система) | Ошибка загрузки не трогает прежний контент | Последний рабочий манифест | Атомарная запись, `ContentSyncService` |

## Продуктовые правила (меняются без переписывания UI)

| Правило | Значение | Где |
|---|---|---|
| Рекомендация частей тела | 2–3, без ограничения | Текст на экране выбора |
| Рекомендация упражнений | 10–12, без ограничения; цвет нейтральный, в диапазоне — зелёный | `WorkoutEstimate.recommendedRange` |
| Оценка времени | 4–6 мин на упражнение | `WorkoutEstimate.minutes` |
| Таймер отдыха | 30 / 60 с, по умолчанию 60, вкл | `AppSettings` |
| Автозапуск отдыха | После «Подход выполнен», кроме последнего известного подхода | `SetsPanel` |
| Автосинхронизация | При запуске / возврате, не чаще раза в 30 мин; сразу — если что-то не докачано | `ContentSyncService.autoSyncInterval` |
| Запас свободного места | 300 МБ не занимаем | `MediaDownloader.reserveBytes` |
| Видео заранее | Только по Wi-Fi (не на дорогой сети) | `ContentSyncService.downloadQueue` |

## Платформы

Нативное iOS/iPadOS 14+, SwiftUI. Только тёмная тема. iPhone — портрет; iPad — все ориентации, контент ограничен шириной 720 pt по центру (стандарт §13.1).

## Текущие эксперименты

| Эксперимент | Гипотеза | Критерий | Решение после пробы |
|---|---|---|---|
| Автозапуск отдыха после «Подход выполнен» | Меньше касаний между подходами | Андрей не выключает таймер и не жмёт «Пропустить» сразу после старта | Оставить / сделать только ручным |
| Счётчик подходов без колонки «Подходы» | Полезен и без общего числа | Андрей отмечает подходы, а не только листает карточки | Оставить / скрыть без колонки |
| Порядок «Да, хочу ещё» (синяя) и «Нет, закончить» (красная, ниже) | Обе кнопки заметны, случайного завершения нет | Нет жалоб на случайное завершение | Поменять акценты |

## Осознанные отклонения от стандарта

| Требование | Отклонение | Причина | Риск и проверка |
|---|---|---|---|
| Undo-тост после обычной мутации | Отметка подхода отменяется кнопкой ↶, а не тостом | Тост мешал бы таймеру отдыха на той же панели | Проверить на пробе, находит ли Андрей ↶ |
| Обратное действие для «Прервать без сохранения» | Нет — только подтверждение с последствиями | Сохранять выброшенную тренировку противоречит смыслу действия | Нужен ли «черновик» прерванной — по пробе |
| Серверная валидация (2.5) | Сервера нет | Данные пользователя в CloudKit, контент только читается | — |
| Аналитика и события (1.3) | Нет | Личное приложение одного человека | Наблюдения записывать вручную (`USABILITY_OBSERVATIONS.md`) |
| Очередь мутаций для offline (11.3) | Нет своей очереди | Core Data пишет локально; без синхронизации досылать нечего | При включении CloudKit — проверить на двух устройствах в авиарежиме |
| Несколько устройств одного пользователя (§13.1) | Данные не переносятся между iPhone и iPad | Решение 2026-09-19: без платного Apple Developer | Настройки прямо говорят «на другое устройство не переносятся»; тексты про iPad скрыты. Если Андрей реально тренируется с двух устройств — вернуться к решению |
| Обновление без участия пользователя | Раз в 7 дней нужна переустановка из Xcode | Бесплатная подпись Apple | Данные при переустановке сохраняются; проверить, не мешает ли это Андрею |

## Критерии приёмки (ТЗ §9 + стандарт)

- [ ] Готовая тренировка начинается за 3 касания, повтор своей (сохранённый выбор) — за 4.
- [ ] Видео не запускается само: только по касанию конкретного видео.
- [ ] После последнего упражнения — «Ещё хочешь?»; «Да» → общий список с отметкой «Сделано сегодня»; «Нет» → итог и запись в истории.
- [ ] Таймер 30/60 с, выключается; продлевается и пропускается; переживает сворачивание.
- [ ] Закрыть приложение посреди тренировки → при запуске «Продолжить» с того же упражнения и подходов.
- [ ] ~~Избранное, история и настройки появляются на втором устройстве без действий пользователя~~ — отложено вместе с платным аккаунтом (2026-09-19). Вместо этого: данные переживают переустановку из Xcode и попадают в резервную копию устройства.
- [ ] Напоминания приходят по расписанию; при запрете уведомлений есть путь в настройки iOS.
- [ ] Женя меняет таблицу или файл → изменение у Андрея после обновления, без разработчика.
- [ ] Без интернета работает всё скачанное; статус понятен и не выглядит ошибкой.
- [ ] Все действия выполняются одной рукой, цели касания не меньше 44 pt, VoiceOver читает кнопки-иконки.
- [ ] Всё это проверено на реальных iPhone и iPad.
