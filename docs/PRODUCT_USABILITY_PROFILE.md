# Product Usability Profile — Тренажёр для Андрея (веб-приложение)

Стандарт: `USABILITY_STANDARD.md` v1.5 (копия; оригинал — `~/Claude-Workspace/СТАНДАРТ-ЮЗАБИЛИТИ-ДЛЯ-НОВЫХ-ПРОДУКТОВ.md`).
Действующий профиль с 2026-09-19. Предыдущая, нативная версия — `PRODUCT_USABILITY_PROFILE_NATIVE.md` (заморожена).

## Аудитория и контекст

- Пользователь — Андрей, один человек, домашние тренировки с гантелями. Телефон лежит рядом, руки заняты: нужны крупные кнопки и минимум касаний между подходами.
- Устройства: iPhone (основное), iPad. Физического доступа к устройствам у команды нет — установка и обновления только удалённо, по ссылке.
- Автор контента — Женя, нетехнический человек, ведёт таблицу и папки Drive. Изменения появляются в приложении через ~10 минут.

## Основная ценность

- Первая ценность: начать тренировку. Готовую — за 3 касания; повтор своей — за 4, выбор сохраняется.
- При следующем открытии: карточка «Незавершённая тренировка → Продолжить».
- Завершённая сессия: «Нет, закончить» или «Завершить и сохранить» → запись в истории.

## Платформа (`PROFILE`)

PWA: HTTPS-адрес `trenazher-135-181-197-13.nip.io`, установка «На экран „Домой“», standalone. Стандарт §13:

| Требование §13 | Как выполнено |

| Нет ложного обещания офлайна | Офлайн реален: service worker, кэш оболочки, контента, фото; видео — только скачанные, об этом сказано прямо |
| Установка не обязательна | Всё работает и во вкладке Safari |

## Прямые и обратные действия

Как в нативной версии (перенесены 1:1), с отличиями:

| Прямое | Обратное | Реализация |
|---|---|---|
| Выбрать часть тела / упражнение | Снять; «Сбросить выбор» | Черновик в localStorage |
| Начать тренировку | Свернуть (⌄) и «Продолжить»; завершить; прервать | Сессия в localStorage после каждого действия |
| Подход выполнен | ↶ снять отметку | Кнопка на нижней панели |
| Отдых | «Пропустить», «+15 с» | Таймер от времени окончания |
| Следующее | ‹ Предыдущее; из «Ещё хочешь?» — «Вернуться к последнему» | |
| «Да, хочу ещё» | ‹ Назад к вопросу | |
| Завершить | Удалить запись → тост «Отменить» (без подтверждения) | Снимок записи с тем же ID; при нуле подходов — тост «закрыта без записи» |
| Прервать без сохранения | Необратимо — подтверждение с последствиями | `window.confirm` |
| ♡ | ♡ снять → тост «Отменить» | |
| Скачать видео для офлайна | «Удалить скачанные видео» (подтверждение) — выключает и автодокачку | Cache Storage; недостающее докачивается само при запуске, пока включено |
| Добавить напоминание в Календарь | Удалить событие в Календаре iPhone | Подсказка на экране |
| Восстановить из файла | Не удаляет существующее — только добавляет недостающее; тост «Отменить» откатывает весь импорт; настройки берутся из копии только на нетронутом устройстве | Объединение без дублей, снимок состояния до импорта |
| Обновление контента (система) | Ошибка сети не трогает прежний контент | Манифест в кэше и localStorage |
| Сбой экрана | Экран «Что-то пошло не так»: данные целы, «Перезапустить» | ErrorBoundary |

## Визуальная система (`PROFILE`)

Подобрана скиллом `ui-ux-pro-max`, разбор его рекомендаций и что из них принято — `design-system/trenazher/MASTER.md`. Действующие значения — `web-app/src/styles.css`.

| Роль | Токен | Значение | Контраст |
|---|---|---|---|
| Фон | `--bg-top` / `--bg-bottom` | `#06142f` → `#0c2966` | белый текст 18.3:1 |
| Карточка и её граница | `--card` / `--stroke` | `#12306b` / `#4576cc` | граница к фону 3.09:1 |
| Главное действие | `--accent` + `--on-accent` | золото `#f0b429`, текст `#06142f` | 9.8:1 |
| Акцент текстом и иконкой | `--accent-text` | `#ffd166` | 8.8:1 на карточке |
| Второстепенное действие | `--blue-fill` | `#2f63d6`, белый текст | 5.4:1 |
| Продолжить / успех | `--green-fill` + `--on-accent` | `#3fd08a`, текст `#06142f` | 9.2:1 |
| Необратимое и сбои | `--danger` | `#ff7a7f` | 5.0:1 |
| Кольцо фокуса | `--accent-text`, 3 px, отступ 2 px | | ≥ 3:1 на любом фоне |

Правила:

- **Синяя база — из ТЗ** («Московское Динамо»), **акцент — золото** вместо красного: красный остаётся только за необратимым и сбоями, чтобы предупреждение не спорило с обычной кнопкой.
- **Одна золотая кнопка на экран** — то действие, которое делают следующим и чаще всего. Во время упражнения это «Подход выполнен»; когда подходы отмечены — «Следующее упражнение».
- **Шрифт системный** (`-apple-system`), размер слушается Dynamic Type; цифры таймера и счётчиков — `tabular-nums`, чтобы не дёргались по ширине.
- **Иконки — свои SVG** (`web-app/src/ui/icons.tsx`), эмодзи как иконки не используются.
- **Анимации почти нет**, `prefers-reduced-motion` отключает остатки.

## Продуктовые правила

| Правило | Значение | Где |
|---|---|---|
| Рекомендация частей тела / упражнений | 2–3 / 10–12, без ограничений; цвет нейтральный | `BodyParts`, `session.ts` |

| Видео | H.264 MP4, длинная сторона ≤ 1280, CRF 27 | `sync.py` |
| Обновление приложения | Не перезагружается само посреди подхода — баннер «Обновить» / «Позже» | `registerType: prompt` |
| Окно отмены | Тост с «Отменить» — 8 с, без действия — 2,5 с | `showToast` |
| Обращение | На «ты», голос Жени | Все тексты интерфейса и отчёта |

## Текущие эксперименты

| Эксперимент | Гипотеза | Критерий | Решение |
|---|---|---|---|
| Напоминания через Календарь вместо push | Хватит повторяющегося события, сервер рассылок не нужен | Андрей добавил событие и не просит «уведомления из приложения» | Оставить / сделать Web Push |
| Автозапуск отдыха | Меньше касаний | Не жмёт «Пропустить» сразу после старта | Оставить / только вручную |
| Видео офлайн по кнопке | Андрей тренируется дома с Wi-Fi, офлайн нужен редко | Смотрит видео онлайн без жалоб на загрузку | Оставить / качать всё автоматически |

## Осознанные отклонения от стандарта и ТЗ

| Требование | Отклонение | Причина | Риск и проверка |
|---|---|---|---|
| ТЗ: нативное приложение iOS | PWA | Без платного Apple Developer и без доступа к iPhone нативную версию не установить удалённо | Проверить на iPhone: установка, звук таймера, календарь, видео |
| ТЗ: push-напоминания | Событие в Календаре iPhone | Web Push требует своего сервера рассылок | Эксперимент выше |
| ТЗ: синхронизация iPhone ↔ iPad | Резервная копия файлом | Нет аккаунта-посредника; свой сервер синхронизации — вне MVP | Если Андрей реально тренируется с двух устройств — делать синхронизацию через сервер |
| Сигнал отдыха в фоне | Звук только при открытом экране | Веб без push не может будить телефон | Предупреждение в Настройках; Wake Lock держит экран включённым |
| Undo-тост для подхода | Кнопка ↶ | Тост мешал бы панели таймера | Проба |
| Аналитика | Нет | Личное приложение | Наблюдения — вручную |
| Цели касания ≥ 44 px | Дни недели 37×44 px на ширине 360 | Семь дней в одну строку шире не помещаются; две строки ломают узнаваемый выбор | Смотреть на пробе, промахивается ли Андрей |

## Критерии приёмки

- [ ] Андрей открывает ссылку в Safari и ставит приложение на экран «Домой» по подсказке, без помощи.
- [ ] Готовая тренировка — за 3 касания, повтор своей — за 4.
- [ ] Видео не запускается само, только по касанию конкретного видео.
- [ ] «Ещё хочешь?» → «Да» → общий список с «Сделано сегодня»; «Нет» → итог и история.
- [ ] Таймер 30/60 с, «+15», «Пропустить», звук при открытом экране; экран не гаснет во время тренировки.
- [ ] Закрыть приложение посреди тренировки → «Продолжить» с того же места.
- [ ] Женя меняет таблицу → через ~10 минут изменение у Андрея, без разработчика.
- [ ] Без интернета: приложение открывается, упражнения и фото на месте, скачанные видео играют.
- [ ] Напоминание добавляется в Календарь и срабатывает.
- [ ] Резервная копия сохраняется и восстанавливается без дублей.
- [ ] Всё проверено на реальном iPhone.
