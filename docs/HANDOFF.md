## Частые операции

Выложить приложение и синхронизатор:

```bash
./deploy/deploy.sh
```

Лог синхронизации:

```bash
ssh -i ~/.ssh/familybot root@135.181.197.13 'journalctl -u trenazher-sync -n 40 -o cat'
```

Отчёт по контенту — что сопоставилось и что Жене поправить:

```bash
ssh -i ~/.ssh/familybot root@135.181.197.13 'cat /var/lib/trenazher/content-report.md'
```

Запустить синхронизацию сейчас, не ждать таймер:

```bash
ssh -i ~/.ssh/familybot root@135.181.197.13 'systemctl start --no-block trenazher-sync.service'
```

Сменить ключ Google. Вводит владелец сам, скрыто; ключ не присылать в чат:

```bash
ssh -t -i ~/.ssh/familybot root@135.181.197.13 trenazher-set-key
```

## Если что-то сломалось

| Симптом в логе | Причина | Что делать |
|---|---|---|
| `Нет доступа к таблице или папке` | Папка перестала быть открытой по ссылке | Женя: «Поделиться» → «Все, у кого есть ссылка» → «Читатель» |
| `API_KEY_IP_ADDRESS_BLOCKED` | IP сервера не совпадает с ограничениями ключа | Google Cloud → Credentials → `trenazher-server` → добавить IP из сообщения. Сервер ходит в Google по IPv6 |
| `API key not valid` | Ключ введён с ошибкой или удалён | `trenazher-set-key` заново |
| `Google временно ограничил скачивание` | Google блокирует массовое скачивание («Sorry…») | Ничего: следующий запуск докачает. Не запускать синхронизацию вручную много раз подряд |
| В приложении «обрабатывается на сервере» | Видео ещё не пережато | Подождать; первая обработка большой порции — до часа |
| Упражнение без фото, хотя файл есть | Имя файла не совпало с названием | Женя вписывает имя файла или ссылку в ячейку (см. отчёт) |
| Swift-тесты падают с `signal code 11` после переноса папки | В кэше сборки старые абсолютные пути | `rm -rf ios-app/TrenazherKit/.build` и снова `run-tests.sh` |

## Правила

- Секреты в репозиторий не попадают: ключ только на сервере, `Secrets.xcconfig` в `.gitignore`.
- ID упражнений (`часть тела/название` в нижнем регистре) одинаковы в Swift и Python — на них ссылаются избранное и история. Менять только с миграцией.
- nginx общий с другими сайтами: правим только `sites-available/trenazher`, перед перезагрузкой — `nginx -t`.
- После изменений: `docs/CHANGELOG.md`, профиль юзабилити, копия `docs/` в workspace.
