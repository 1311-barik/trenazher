# Тренажёр — веб-приложение (PWA)

**Адрес:** https://trenazher-135-181-197-13.nip.io

Основная версия с 2026-09-19. Нативное iOS-приложение (`../ios-app/`) заморожено: без платного Apple Developer и без доступа к iPhone Андрея его не установить. Веб-версия ставится по ссылке: Safari → «Поделиться» → «На экран „Домой“». Работает на iPhone и iPad, обновляется сама, ничего не стоит.

## Как устроено

```
Google-таблица + папки Drive (Женя)
        │  по команде ./deploy/pull-content.sh, по API-ключу (ключ только на сервере)
        ▼
content-sync/sync.py на сервере ──► /var/www/trenazher/content/
   разбор таблицы, сопоставление файлов,          manifest.json
   фото → 1400 px + миниатюры 400 px,             media/photos|thumbs|videos|posters
   видео iPhone (MOV) → H.264 MP4 ≤ 1280 px + обложка
        │
        ▼
web-app (этот каталог) ── nginx, HTTPS (Let's Encrypt) ──► Safari / экран «Домой»
```

- **Логика контента** — `../content-sync/trenazher_content.py`, порт Swift-версии с теми же правилами и ID упражнений. 11 тестов на реальной выгрузке таблицы, включая сквозной прогон фото и видео через ffmpeg (на сервере).
- **Приложение** — React + TypeScript + Vite, без UI-библиотек. Экраны те же, что в нативной версии.
- **Данные Андрея** — история, избранное, настройки, черновик и идущая тренировка. Хранятся в `localStorage` устройства и сохраняются после каждого действия. В Настройках есть резервная копия в файл и восстановление с объединением, без дублей.
- **Офлайн** (service worker, `src/sw.ts`):
  - оболочка приложения лежит в кэше заранее;
  - список упражнений: сначала сеть, без сети — последняя версия;
  - фото и обложки докачиваются все после загрузки;
  - видео — по кнопке «Скачать для офлайна» у каждого видео или «Скачать все» в Настройках; из кэша играют с перемоткой.
- **Напоминания** — повторяющееся событие в Календаре iPhone. nginx отдаёт `.ics` по параметрам из приложения (`/reminder.ics`, см. `../deploy/trenazher.nginx`), своего сервера рассылок нет.
- **Таймер отдыха** считает от времени окончания и не отстаёт при сворачивании. Звук — через Web Audio: работает, пока экран не заблокирован. «Не гасить экран» — Wake Lock, где браузер его поддерживает.

| Синхронизатор | `/opt/trenazher/content-sync`, кэш оригиналов и отчёт — `/var/lib/trenazher` |

Проект Google Cloud `trenazher-509109`, ключ `trenazher-server`: только Sheets API + Drive API, только с IP сервера — **и IPv4 135.181.197.13, и IPv6 2a01:4f9:c015:a064::1** (в Google сервер ходит по IPv6). Сменится сервер — обновить ограничения ключа |
| Таймер | `trenazher-sync.timer` **выключен с 2026-09-27** — контент подтягивается по команде `./deploy/pull-content.sh` (запускает `trenazher-sync.service`, `nice 19`) |
| nginx | `/etc/nginx/sites-available/trenazher`, сертификат Let's Encrypt продлевает `certbot.timer` |

Ключ вводит владелец сам — скрытым вводом, ключ не попадает ни в историю команд, ни в чат:

```bash
ssh -t -i ~/.ssh/familybot root@135.181.197.13 trenazher-set-key
```

Лог синхронизации и отчёт по контенту:

```bash
ssh -i ~/.ssh/familybot root@135.181.197.13 'journalctl -u trenazher-sync -n 50; cat /var/lib/trenazher/content-report.md | head -40'
```

## Статус на 2026-09-19

- Выложено и работает по HTTPS: приложение, офлайн-кэш, календарная ссылка. Соседние сайты сервера проверены — в порядке.
- Синхронизация работает с 2026-09-19: ключ введён, Женя открыла папку по ссылке. Первая загрузка: 40 упражнений, 39 файлов, привязанных автоматически (фото у 15 упражнений); видео сжаты в 5–35 раз без потери длительности. Остальные файлы появятся, когда Женя впишет их имена в таблицу.
- Google временно ограничивает массовое скачивание с сервера («Sorry…»). Синхронизация делает паузы между файлами, при ограничении останавливается и докачивает остальное при следующем запуске.
- Проверено в браузере: весь сценарий тренировки — выбор, подходы, таймер, «Ещё хочешь?», добор, итог, история. На реальном iPhone ещё не проверялось: установка на экран «Домой», звук таймера, календарь, видео.

## Важно про адрес

Данные Андрея привязаны к адресу сайта. Если позже переехать на свой домен, история сама не переедет. Перед переездом: Настройки → «Сохранить резервную копию» на старом адресе, «Восстановить из файла» на новом. Проще выбрать постоянный адрес до того, как Андрей начнёт тренироваться всерьёз.
