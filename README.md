# Тренажёр для Андрея

Личное приложение для силовых тренировок с гантелями: готовые тренировки или своя подборка по частям тела, карточки упражнений с фото, техникой и видео, таймер отдыха, история. Контент ведёт Женя в Google-таблице и папках Google Диска. Приложение подтягивает её изменения само, без разработчика.

## Устройство

```
Google-таблица + папки Drive (Женя)
        │  по команде: ./deploy/pull-content.sh (API-ключ только на сервере)
        ▼
content-sync/  ──►  /var/www/trenazher/content/  (manifest.json + фото/видео)
        │
        ▼
web-app/  ── nginx + HTTPS ──►  iPhone / iPad (экран «Домой», офлайн)
```

| Папка | Что внутри |
|---|---|
| `web-app/` | **Основная версия.** PWA на React + TypeScript + Vite: все экраны ТЗ, офлайн (service worker), напоминания через Календарь, резервная копия. Подробно — `web-app/README.md` |
| `content-sync/` | Синхронизация на сервере (Python): разбор таблицы, сопоставление файлов, фото → JPEG, видео iPhone → H.264 MP4 |
| `deploy/` | nginx, systemd-таймер, `deploy.sh`, `trenazher-set-key` |
| `ios-app/` | Нативная версия SwiftUI (iOS 14+). **Заморожена**: без платного Apple Developer и доступа к iPhone Андрея её не установить. Код рабочий — `ios-app/README.md` |
| `docs/` | ТЗ, лог проекта, передача дел, юзабилити |

## Быстрый старт

```bash
cd web-app && npm install && npm run dev
```

Разработка идёт на живом контенте: `/content` проксируется с боевого сервера.

```bash
cd web-app && npm test
```

```bash
cd content-sync && python3 -m unittest discover -s tests -v
```

```bash
./deploy/deploy.sh
```

Подтянуть изменения Жени из таблицы и папок Drive — только по команде владельца (автоматический таймер выключен):

```bash
./deploy/pull-content.sh
```
