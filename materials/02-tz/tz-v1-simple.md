# ТЗ: Приложение-тренажёр для Андрея

---

## 1. О ПРИЛОЖЕНИИ

**Назначение:** Персональное приложение для выбора и проведения силовых тренировок.

**Кто использует:** Только Андрей (на iPhone и iPad).

**Кто добавляет контент:** Женя (упражнения, видео, описания).

**Главная идея:** Андрей открывает приложение, видит тренировки, выбирает готовую программу или собирает свою из упражнений. Во время тренировки видит упражнение, описание, видео и может засекать время.

---

## 2. ОСНОВНЫЕ ЭКРАНЫ

### Главный экран (Home)
- **Что видно:**
  - Две большие карточки:
    - "Готовые тренировки" 
    - "Собрать свою тренировку"
  - Внизу кнопка "Избранные" (если нужно)

- **Что происходит:**
  - Нажимаешь на карточку → переходишь в соответствующий раздел

---

### Экран "Готовые тренировки"
- **Что видно:**
  - Список программ (например: "Ноги", "Спина", "Грудь")
  - Каждая программа - это карточка с названием и количеством упражнений

- **Что происходит:**
  - Нажимаешь на программу → открывается список упражнений этой программы
  - Нажимаешь на упражнение → начинается тренировка

---

### Экран "Собрать свою тренировку"
- **Что видно:**
  - Список ВСЕ упражнений из базы
  - Поле поиска, чтобы найти нужное

- **Что происходит:**
  - Нажимаешь на упражнение → оно добавляется в "сегодняшнюю тренировку"
  - Кнопка "Начать тренировку" → переходишь на экран тренировки

---

### Экран "Тренировка"
- **Что видно:**
  - Большое изображение упражнения
  - Название упражнения
  - Описание (что делать, как дышать)
  - Видео (если есть)
  - Таймер (опционально: если нужно засекать время)
  - Кнопки:
    - "← Предыдущее" / "Следующее →" (переключение между упражнениями)
    - "Завершить тренировку"

- **Что происходит:**
  - Переходишь по упражнениям стрелками
  - Нажимаешь "Завершить" → возвращаешься на главный экран

## 4. ОТКУДА БЕРЁТСЯ КОНТЕНТ

### Как работает с Google Drive:
1. Женя создаёт папку на Google Drive с упражнениями
2. В папке файлы: фото упражнения + видео + описание
3. Андрей один раз в приложении нажимает "Обновить контент"
4. Приложение скачивает новые упражнения с Drive

**Структура в Google Drive:**
```
Тренировки Андрея/
├── Упражнение_1/
│   ├── photo.jpg (фото упражнения)
│   ├── video.mp4 (видео, до 20 сек)
│   ├── description.txt (описание)
│   └── exercise.json (название, группа мышц)
├── Упражнение_2/
│   └── ...
├── Программа_1.json (готовая программа: какие упражнения включает)
└── ...
```

**Как обновляется:**
- Андрей открывает приложение
- Нажимает "Обновить" в настройках
- Приложение скачивает обновлённый контент с Drive
- Всё сохраняется на устройстве (не нужен интернет дальше)

## 5. ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Стек:
- **iOS/iPadOS:** SwiftUI или UIKit
- **Язык:** Swift
- **База данных:** SQLite (хранится на устройстве) или простые JSON файлы
- **Интеграция с Google Drive:** API или просто прямые ссылки на файлы

### Данные:
- **Видео:** MP4, H.264, 720p, макс 20 сек, 10–15 MB каждое
- **Фото:** JPG, 1200×800 px, сжатое
- **Описание:** простой текст (как делать, дышать, правильное выполнение)

### Адаптация:
- **iPhone:** вертикальная ориентация, карточки под друг другом
- **iPad:** горизонтальная ориентация, если нужно - сбоку видео, справа описание

## 6. СЦЕНАРИИ ИСПОЛЬЗОВАНИЯ

### День обычный:
1. Андрей открывает приложение
2. Нажимает "Готовые тренировки"
3. Выбирает "Спина"
4. Видит 7 упражнений для спины
5. Нажимает на первое "Подтягивания"
6. Видит: фото, описание, видео, таймер
7. Переходит на следующее упражнение стрелкой
8. После последнего - "Завершить тренировку"

### Женя добавила новое упражнение:
1. Женя кладёт папку упражнения в Google Drive
2. Андрей нажимает "Обновить контент"
3. Новое упражнение появляется в приложении
