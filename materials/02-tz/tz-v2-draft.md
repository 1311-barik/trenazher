# Техническое задание: Приложение-тренажёр для Андрея
**Версия 2.0** | Дата: сентябрь 2026

---

## 1. Обзор проекта

Приложение-тренажёр для iOS/iPadOS позволяет Андрею выбирать готовые силовые программы или составлять собственные тренировки. Основная фишка — контент хранится на Google Drive (shared folder) и синхронизируется по запросу.

**Платформы:** iOS 14+ и iPadOS 14+

---

## 2. Основной функционал (MVP)

### Экран 1: Главная (Home)
- Карточки: "Готовые программы", "Мои программы", "Упражнения", "Синхронизация"
- Каждая карточка — переход в соответствующий раздел
- Простой, интуитивный дизайн

### Экран 2: Готовые программы
- Список программ (созданы Женей в Google Drive)
- Карточка программы: название, описание, кол-во упражнений
- Кнопка "Начать тренировку"

### Экран 3: Мои программы
- Программы, составленные Андреем
- Возможность редактировать, удалить, начать тренировку

### Экран 4: Упражнения (База)
- Полный список всех упражнений с фильтром/поиском
- На карточке упражнения: название, описание, видео (встроенный плеер)

### Экран 5: Тренировка (Процесс)
- Упражнения в очереди (название, изображение, описание)
- Встроенный видеоплеер
- Навигация: "Пред. упр." / "Далее упр."
- Таймер (на случай, если нужны паузы между подходами)
- Отсчёт подходов (1/3, 2/3, 3/3)
- Кнопка "Пропустить"
- **При выходе из приложения** — сохраняется позиция упражнения и прогресс

### Экран 6: Конструктор программ
- Выбрать упражнения из базы
- Задать кол-во подходов, повторений, отдых
- Сохранить как программу
- Просмотр и редактирование сохранённых программ

### Экран 7: Синхронизация
- **Прогресс-бар** — процент загрузки контента
- **Логи** — список загруженных файлов (программы, видео, упражнения)
- Кнопка "Начать синхронизацию"
- При прерывании — **автоматическая синхронизация при следующем открытии приложения**
- Статус: успешно/ошибка

## 3. Режим работы

**С интернетом:**
- Синхронизация работает нормально
- Видео проигрываются из памяти (после загрузки)

**Без интернета:**
- Приложение не работает (только отображение загруженного контента)
- При попытке синхронизации — ошибка "Нет подключения"

## 4. Хранение данных

### SQLite база данных (локально на устройстве)

**Таблицы:**

```sql
-- Программы
Programs
- id (UUID)
- name (TEXT)
- description (TEXT)
- createdBy (TEXT) -- "Женя" или "Андрей" (custom)
- isCustom (BOOL) -- false для готовых, true для своих
- version (INT) -- для отслеживания версий
- createdAt (TIMESTAMP)
- updatedAt (TIMESTAMP)

-- Упражнения в программе
ProgramExercises
- id (UUID)
- programId (FK)
- exerciseId (FK)
- order (INT)
- sets (INT) -- кол-во подходов
- reps (INT) -- кол-во повторений
- restSeconds (INT) -- отдых в секундах

-- Упражнения (база)
Exercises
- id (UUID)
- name (TEXT)
- description (TEXT)
- videoPath (TEXT) -- путь к видео в Documents/Videos/
- imagePath (TEXT) -- путь к изображению
- muscleGroup (TEXT) -- спина, грудь, ноги и т.д.
- difficulty (TEXT) -- easy, medium, hard
- version (INT)
- updatedAt (TIMESTAMP)

-- История тренировок (для сохранения прогресса)
WorkoutHistory
- id (UUID)
- programId (FK)
- exerciseId (FK)
- startedAt (TIMESTAMP)
- completedAt (TIMESTAMP, nullable)
- currentExerciseIndex (INT) -- где пользователь остановился
- setsCompleted (INT) -- сколько подходов закончено
- isCompleted (BOOL)

-- Синхронизация (логи)
SyncLogs
- id (UUID)
- timestamp (TIMESTAMP)
- action (TEXT) -- "download", "update", "delete"
- resourceType (TEXT) -- "program", "exercise", "video"
- resourceId (TEXT)
- status (TEXT) -- "success", "error", "pending"
- errorMessage (TEXT, nullable)
```

## 6. Синхронизация (Логика)

### Процесс синхронизации:

1. **Проверка подключения** — есть ли интернет?
2. **Загрузка метаданных** — скачиваются JSON-файлы программ и упражнений
3. **Сравнение версий** — если версия на Drive выше, чем локально → обновить
4. **Загрузка видео и изображений** — сохраняются в `Documents/Videos/` и `Documents/Images/`
5. **Обновление БД** — запись новых/обновленных данных в SQLite
6. **Логирование** — запись действия в таблицу `SyncLogs`
7. **Прерывание** — если интернет упал, приложение запомнит, где остановилось, и повторит при следующем открытии

### Версионирование программ:

- Если Женя выпустила "Спина v2", она **добавляется как новая программа**, не перезаписывает старую
- У каждой программы свой `id` и `version`
- Если Андрей сделал кастомную программу "Спина", она **не конфликтует** с готовыми программами Жени

## 7. Хранение видео и памяти

### Расчёт памяти:
- 200 видео × 15 MB = 3 GB
- На iPhone 12+ хватит памяти (стандартная на 128+ GB)
- **Альтернатива**: если памяти недостаточно, видео может **проигрываться из памяти** без сохранения на диск (streaming), но это усложнит архитектуру

### Текущий подход:
- Видео **загружаются и сохраняются локально**
- Если видео не поместилось на iPhone — пользователь видит ошибку синхронизации
- Решение: либо сжимать видео на Google Drive (h.264, 720p), либо уменьшить размер файлов

## 8. Обработка ошибок

| Сценарий | Действие |
|----------|----------|
| Нет интернета | Показать ошибку "Подключитесь к интернету" |
| Видео не загрузилось | Повторить попытку; показать последний скачанный кадр |
| Синхронизация прервана | Запомнить позицию; повторить при следующем открытии |
| Видео не поместилось в памяти | Ошибка синхронизации; предложить удалить старые видео |
| Пользователь вышел из приложения | Сохранить прогресс (индекс упражнения, подходы); при возврате продолжить |

## 9. История тренировок

- Каждая начатая тренировка записывается в `WorkoutHistory`
- Сохраняется: время начала, время окончания, текущее упражнение, завершённые подходы
- На главном экране можно показывать статистику: "Тренировок завершено: 42"

## 10. Дизайн

### Цветовая схема: Московское Динамо
- **Основной цвет:** Синий (`#003366` или близкий)
- **Дополнительный:** Белый (`#FFFFFF`)
- **Акценты:** Красный (`#CC0000` для кнопок действий)
- **Фон:** Белый или светло-серый (`#F5F5F5`)
- **Текст:** Темно-синий или чёрный

### Компоненты UI:
- **Карточки программ:** синий фон, белый текст, закруглённые углы (radius 12pt)
- **Кнопки:** синий фон с красным акцентом при нажатии
- **Таймер на тренировке:** крупный белый текст на синем фоне
- **Прогресс-бар синхронизации:** синий цвет заполнения, серый фон

### Размеры (на усмотрение дизайнера/разработчика):
- Отступы между карточками: 16pt
- Размер шрифта заголовка: 24pt
- Размер шрифта текста: 16pt
- Высота карточки программы: 120-160pt
