## Краткое содержание

Женя голосом описывает концепцию приложения-тренажёра. При входе — выбор из двух опций: готовая тренировка (список из 3-4 вариантов, ещё не составлен) или сборка индивидуальной тренировки. При сборке своей тренировки пользователь выбирает 2-3 части тела (попа, руки, спина, ноги, пресс), после чего открывается список упражнений по каждой выбранной части (с миниатюрами фото), отмечаются галочками. Ограничения по числу упражнений нет, но приложение рекомендует 10-12 — под тренировку от 30 минут до 1,5 часа. Карточка упражнения: название, 1-2 фото (подобраны Женей), текстовое описание техники, 2-3 видео (одно — записанное самой Женей, остальные — чужие обучающие). Видео не запускаются автоматически, только по нажатию. Обсуждается таймер отдыха 30/60 секунд между подходами прямо в приложении и навигация кнопкой «Следующее упражнение». После последнего упражнения из выбранного списка приложение спрашивает, хочет ли пользователь продолжить — при согласии открывается общий список для добора упражнений, при отказе тренировка завершается.

## Структура приложения (как описала Женя)

- Вход: «готовая тренировка» vs «собрать самому».
- Готовые тренировки: 3-4 варианта (список пока не составлен).
- Своя тренировка: выбор частей тела (попа/руки/спина/ноги/пресс, рекомендация — 2-3 из них) → список упражнений по каждой части с фото-миниатюрами → отметка галочками (рекомендация 10-12 упражнений, без жёсткого лимита).
- Карточка упражнения: название → 1-2 фото → текстовое описание → 2-3 видео (своё + чужие с техникой выполнения), видео грузятся по запросу.
- Возможный таймер отдыха 30/60 сек между подходами (Женя сама не уверена, встраивать ли).
- Навигация: кнопка «Следующее упражнение»; после конца списка — вопрос «ещё хочешь?» с веткой продолжить/закончить.
