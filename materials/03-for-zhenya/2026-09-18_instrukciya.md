# Как вести таблицу «Дрон тренировка»

Приложение берёт упражнения прямо из таблицы и папок «Андрей тренировка» на Google Drive. Ты работаешь как раньше. С 2026-09-27 изменения появляются у Андрея не сами, а после того как ты скажешь Саше, что что-то поменяла, — он подтянет. Видео с телефона можно загружать как есть: сервер сам уменьшит их, чтобы они быстро открывались.

## 1. Один раз: открыть доступ по ссылке

Папка «Андрей тренировка» → «Поделиться» → «Все, у кого есть ссылка» → **Читатель**. Без этого приложение не увидит таблицу и файлы.

## 2. Что уже работает само

- **Разделы.** Руки, Попа, Ноги, Живот, Плечи, Грудь, Спина, Смесь мышц — каждый раздел в таблице становится частью тела в приложении. Новый раздел появится сам.
- **Часть тела и группа мышц только в первой строке раздела.** Так и оставляй, приложение понимает.
- **Колонка «Гантели +».** Показывается на карточке: «Гантели + стул».
- **Описание.** Переносы строк сохраняются.

## 3. Главное: как указать фото и видео

Сейчас в колонках «Фото из интернета», «Чужое видео», «Женя видео» стоит «есть». Приложению нужно понять, **какой именно** файл. Способы — любой на выбор, в одной ячейке можно смешивать:

1. **Имя файла.** Например: `Бицепс. Молот`. Расширение (.JPG, .mov) писать не нужно.
2. **Ссылка на файл.** Правый клик по файлу в Drive → «Копировать ссылку» → вставить в ячейку.
3. **Несколько файлов.** Каждый с новой строки (Ctrl+Enter / ⌘+Enter внутри ячейки) или через «;».
4. **«нет» или «нет и не будет».** Файла не будет, приложение не будет его искать.
5. **«есть».** Сработает, только если файл называется так же, как упражнение: «Пресс. Мертвый жук» для «Мертвый жук». Так уже нашлись 15 фото.

Приложение не угадывает похожие названия: пусть лучше не будет фото, чем окажется чужое.

## 4. Готовые тренировки — новый лист «Тренировки»

Добавь в эту же таблицу лист с названием **«Тренировки»** и колонками:

| Тренировка | Описание | Упражнение |
|---|---|---|
| Руки и пресс | 40 минут, без инвентаря | Молот |
| | | Диагональный молот |
| | | Мертвый жук |
| Спина | | Шраги с гантелями |
| | | Вокруг света |

- Название и описание — только в первой строке тренировки, ниже по одному упражнению в строке, как в основной таблице.
- Упражнение — точно как в основной таблице. Если одно название встречается в двух разделах, пиши «Попа. Приседания».
- Новую версию («Спина v2») добавляй отдельной тренировкой: старая не пропадёт.

## 5. По желанию — колонка «Подходы»

Если добавить колонку **«Подходы»** с числом (3, 4…), на экране тренировки появится счётчик «Подход 2 из 3», а таймер отдыха будет знать, когда подходы закончились. Без колонки всё тоже работает: Андрей просто отмечает подходы сам.

## 6. Где смотреть, что не так

В приложении: Настройки → «Проверка контента» — там написано, какая строка и какая ячейка не сопоставились. Полный отчёт на сегодня лежит рядом: `2026-09-18_otchet-po-kontentu.md`.
